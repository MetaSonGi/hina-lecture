# 이수증 발급 유저플로우

## 등장인물
- 강사: 수료 기준(진도율·출석률 %)을 설정하는 사람
- 학생: 기준을 달성하고 이수증을 받는 사람

## 플로우 1 — 강사: 수료 기준 설정
1. 강사 화면 → LMS 설정 열기
2. 수료 기준 입력 (예: 진도율 80% 이상, 출석률 80% 이상)
3. 저장 → `config/lms`에 저장됨

## 플로우 2 — 학생: 이수증 발급받기
1. 학생 화면 → 이수증 탭 열기
2. 내 달성 현황 확인
   - 진도율 OO% (기준 OO% 이상) ✅/⬜
   - 출석률 OO% (기준 OO% 이상) ✅/⬜
3. 두 기준을 모두 만족하면 [🏅 이수증 발급받기] 버튼 활성화
   - 미달성 시 버튼 비활성화 + 안내 문구 표시
4. 버튼 클릭
   → 발급번호 생성 (첫 발급 시, 이후 재발급은 기존 번호 유지)
   → Firestore `certificates/{uid}_{classId}`에 발급 기록 저장
   → 이수증 PNG 자동 다운로드 (`이수증_이름.png`)
   → "발급 완료 (발급일)" 표시로 변경
5. [다시 받기]로 재다운로드 가능 (번호는 그대로)

## 플로우 3 — 발급 이력 확인 (강사)
1. 강사 화면에서 학생별 발급 여부 확인 가능
   (발급번호·발급일로 진위 대조)

## 예외 처리
- 기준 미달성: 버튼 비활성화, 어떤 기준이 부족한지 표시
- 네트워크 오류: 발급 실패 시 알림, 기록 저장 안 됨
- 데모 모드: 브라우저 로컬에 저장 (새로고침해도 유지)
