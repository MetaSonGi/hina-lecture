# 이수증 발급 기능 기획서

## 1. 배경
- 메타송이 클래스(효기샘)는 실시간 강의 플랫폼으로, 수강생의 학습 완료를 증명할 수단이 필요함
- 기존 수료증은 기능상 동작하나, 효기샘 브랜딩이 없고 발급번호·발급기관 직인이 없어 공식 문서로 부족함

## 2. 목표
- 효기샘 브랜드의 공식 이수증을 발급한다
- 발급번호로 발급 이력을 식별할 수 있게 한다
- 서명란(발급자 직인)으로 문서의 공신력을 갖춘다
- 학생이 1클릭으로 PNG 다운로드할 수 있게 한다

## 3. 범위
- 대상: 학생 화면의 이수증 발급 영역
- 발급 조건: 기존과 동일 (진도율·출석률 기준 달성)
- 발급 형태: PNG 이미지 다운로드 (1200×850)
- 저장: Firestore `certificates` 컬렉션 (데모 모드는 로컬)

## 4. 요구사항

### 4.1 문구 (확정)
| 영역 | 문구 |
|---|---|
| 브랜드 | 효기샘 |
| 제목 | 이 수 증 |
| 성명 | 성명: OOO |
| 본문 | 위 사람은 효기샘 [과정명] 과정을 성실히 이수하였기에 이 증서를 수여합니다. |
| 실적 | 진도율 OO% · 출석률 OO% |
| 발급번호 | 이수증 발급번호: HGS-2026-XXXXXX |
| 발급일 | 발급일: 2026년 10월 18일 |
| 서명란 | 효기샘 대표 손효기 (직인) |

### 4.2 발급번호 규칙
- 형식: `HGS-YYYY-XXXXXX` (연도 + 6자리 영숫자)
- 한 번 발급된 번호는 재발급해도 유지 (DB에 저장)
- 예: `HGS-2026-A3F9K2`

### 4.3 서명란
- 발급자명: 효기샘 대표 손효기
- 직인: 캔버스에 직접 그리는 붉은색 도장 (효기샘之印)
- 별도 이미지 파일 없이 동작 (정적 사이트 호환)

## 5. 비목표
- 실물 우편 발송, PDF 발급 (PNG만 제공)
- 블록체인 등 외부 검증 시스템 (발급번호는 DB 대조용)
- 강사가 직접 서명하는 기능 (대표 직인으로 대체)
